# Irrigation Department Chatbot

Simple Python Flask website chatbot for a student project about a father working as an irrigation department officer.

## Install
1. Open terminal in `c:\Users\USer\Documents\Chatbot`
2. Create a Python virtual environment (recommended):
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Run
```bash
python app.py
```

Then open `http://127.0.0.1:5000` in your browser.

## Use
- Type questions like:
  - `What is your job?`
  - `What do you do?`
  - `What is irrigation?`
  - `How do you help farmers?`
- The chatbot replies in English and keeps the chat history in the session.
